Se verificó la ausencia total de credenciales expuestas (API keys de Gemini) y se particionó el trabajo en tres commits de alcance semántico limpio:

1. **Commit 1 (`c82f41e`) — Módulos Core y Pruebas Unitarias**:

2. **Commit 2 (`b7564f8`) — Scripts CLI y Herramientas Operativas**:
