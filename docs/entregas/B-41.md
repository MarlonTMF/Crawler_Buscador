### B. Conclusión Técnica Ineludible
- **Un crawler estándar basado en BeautifulSoup / regex sobre el HTML estático NUNCA verá estos 1.606 archivos**, porque nunca existen en el HTML inicial; se generan en el cliente vía JavaScript sobre plantillas combinatorias.
- **Rolando dedujo o parseó este patrón**, como lo confirma su propio log (`batch_logs/asfi_finrural.log:27`):
  `[ASFI_FINRURAL] GENERADOS DESCUBIERTOS | grupos=260 | .../pb/instituciones-financieras-desarrollo`
  `[ASFI_FINRURAL] HTTP TOTAL | requests=1886 | GET=3 | HEAD=1883`
- Rolando probó 1.883 peticiones HEAD secuenciales sobre `int_fin_des/{YYYY}/{MM}/{YYYYMM}_IFD_{Serie}.zip`, de las cuales **1.606** respondieron con HTTP 200 (y 227 fallaron con 404).
- Se probó una petición HEAD real en vivo desde Python sobre `2024/06/202406_IFD_EstadosFinancieros.zip`:
  - Resultado: **HTTP 200, Content-Type: application/zip, Content-Length: 104.100 bytes**.
- Esto confirma formalmente la necesidad de la **Decisión D-17** (Extrapolación de Serie Observada / Generador de URLs desde plantillas identificadas en JS/HTML) en el bloque **B-47**.

3. **ASOFIN (195 faltantes de Rolando)**:

4. **IBCH (14 faltantes de Rolando)**:
