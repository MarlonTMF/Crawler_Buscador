# B-02 · Fix de mailto:/tel: en discovery

- **Ejecutado por:** Antigravity
- **Fecha:** 2026-09-17
- **Estimado:** 15 min · **Real:** 5 min · **Desvío:** -66%
- **Commit:** `35f360a` — fix: descarta enlaces mailto:/tel: que el crawler trataba como páginas

## Qué se hizo

Se corrigió la validación de dominios y filtrado de enlaces en `DiscoveryEngine` (`src/crawler/core/discovery.py`) para descartar enlaces no-HTTP(S) (`mailto:`, `tel:`, `fax:`, `whatsapp:`, `sms:`, `javascript:`) que se encolaban como páginas y causaban reintentos estériles. Se incorporó la prueba de regresión en `tests/test_discovery.py` (5 casos). Adicionalmente, atendiendo el hallazgo de auditoría de B-01, se añadió la excepción `!.env.example` en `.gitignore` y se versionó la plantilla `.env.example`.

## Criterio de aceptación — evidencia

> Los 5 casos de `tests/test_discovery.py` pasan, y —esto es lo que de verdad importa— se confirma que fallan sin el fix:
> ```bash
> git stash -- src/crawler/core/discovery.py
> python -m pytest tests/test_discovery.py -q          # 3 failed, 2 passed
> git stash pop
> ```
