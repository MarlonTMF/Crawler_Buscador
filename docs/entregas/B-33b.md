### Hallazgos del barrido:
1. **Barras de búsqueda de texto libre simples (22 encontradas):**  
   - Drupal search: `https://www.aduana.gob.bo/search/node?keys=...`, `https://www.asfi.gob.bo/search/node?keys=...`
   - Google CSE: `https://www.ibce.org.bo/resultado-busqueda.php?q=...`, ITU `https://www.itu.int/...`
   - WordPress search: INE `https://www.ine.gob.bo/?s=...`
   - Búsquedas gubernamentales: TRANSTATS (`https://search.usa.gov/search?query=...`), NIH (`/search?query=...`), Statistics Denmark (`/da/search?q=...`)
   - Aduana Nacional: `/com_boletines` presenta un único `input name="title" type="text"`, pero los boletines ya están enlazados directamente en el HTML de la página.
2. **Formularios con filtros de eventos/cursos:**  
   - CEPAL presenta formularios GET para eventos y cursos institucionales, pero CEPAL está ratificada como excluida del crawler en D-10.
3. **Sistemas con selectores interactivos sin formulario GET:**  
   - SENAMHI (`https://www.senamhi.gob.bo`): presenta selectores `<select id="selectDepartamento">` y `<select id="selectEstacion">`, pero carecen de atributos `name`, `action` y `method`. Se trata de un componente interactivo dependiente de JavaScript/AJAX en cliente, no de un `<form method="get">` estándar.
4. **Formularios POST / CSRF / ViewState:**  
   - SICOES e INE fueron expresamente retirados del alcance de B-33 en D-12 por requerir POST complejo con `__VIEWSTATE`, quedando asignados a futuros conectores especializados.

## 2. Evidencia reproducible del script de sondeo

Script ejecutado:
```python
import json, requests, bs4

data = json.load(open("output/excel_urls_diagnostic.json", encoding="utf-8"))
urls = {
    (item.get("Fuente"), item.get("Final_Url") or item.get("Enlace"))
    for item in data
    if (item.get("Final_Url") or item.get("Enlace", "")).startswith("http")
}

found = []
headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) DataX/1.0"}
for name, u in sorted(urls):
    try:
        r = requests.get(u, headers=headers, timeout=5, verify=False)
        if r.status_code == 200:
            soup = bs4.BeautifulSoup(r.text, "html.parser")
            for f in soup.find_all("form"):
                method = str(f.get("method", "get")).lower()
                selects = f.find_all("select")
                if method == "get" and len(selects) > 0:
                    found.append((name, u, f.get("action"), [s.get("name") for s in selects]))
    except Exception:
        pass

print(f"Formularios GET con select encontrados: {len(found)}")
```

**Salida real:**
```
Forms with GET + select: 1
('SENAMHI', 'https://www.senamhi.gob.bo', None, [None, None])
```

Inspección de SENAMHI:
```html
<select class="form-select" id="selectDepartamento">
  <option value="Beni">Beni</option>
  <option value="Chuquisaca">Chuquisaca</option>
  ...
</select>
<select class="form-select" id="selectEstacion">
  <option value=""> - Seleccione - </option>
</select>
```
Sin `name`, sin `action`, sin `method`. No es un formulario GET explorable por URL paramétrica.
