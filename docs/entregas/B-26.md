## 1. Resumen Ejecutivo y Qué se Hizo

En cumplimiento estricto de la Decisión D-04 (`docs/decisiones.md:106-126`) y los requerimientos del Bloque B-26 (`docs/plan_bloques.md:842-860`), se implementó una herramienta programática de reporte consolidado (`scripts/reporte_cobertura.py`) que calcula el estado de cobertura de forma reproducible a partir de los datos reales del repositorio, eliminando por completo cualquier recopilación o cálculo manual de cifras (Lección E-15).

### Criterios de Aceptación Cumplidos:
1. **Métricas Desacopladas de D-04 por Separado:**
   - **Track A (Conectividad del Catálogo):** Mide universo total (67), HTTP 200 simple (62), accesibles vía headless (2), cobertura efectiva verificada (64/67 = 95.52%), exclusiones justificadas (3/67 = 4.48%), 100% clasificado (67/67), y entradas asignadas a fuentes con crawler (33/67 = 49.25%).
   - **Track B (Extracción Real de Documentos):** Mide portales onboardeados activos (26), recursos únicos procesados exitosamente por SQL (`COUNT(DISTINCT download_url) WHERE status='PROCESADO_EXITOSAMENTE'` = 2,611), total de filas en bases SQLite (2,633), total de datasets clasificados (59), volumen total procesado (646.03 MB / 677,408,955 bytes), y desglose detallado portal por portal.
2. **Las cifras provienen de los datos, no de recopilación manual (E-15):**
   - Track A se calcula analizando programáticamente `output/excel_urls_diagnostic.json`.
   - Track B se calcula ejecutando consultas SQLite en solo lectura contra cada `output/<fuente>/inventory.db`.
3. **Múltiples Formatos y Modo Estricto para Automatización CI/CD:**
   - `--format text` (consola con tablas y encuadre limpio).
   - `--format markdown` (formato GitHub Markdown listo para auditorías, actas y README).
   - `--format json` (exportación JSON con estructura completa para integración).
   - `--output <path>` (escritura directa a disco opcional).
   - `--strict` (validación de umbrales: Track A >= 95%, Track B >= 25 fuentes y >= 2,500 recursos; retorna exit code 0 o 1).
4. **Pruebas y Verificación:**
   - 8 pruebas unitarias nuevas en `tests/test_reporte_cobertura.py` (mocks aislados y datos reales).
   - Verificación en worktree limpio y aislado (`C:\Temp\wt_b26`): **94 passed in 15.05s** (suite completa).

## 3. Desviaciones del Plan y Decisiones de Bloque

1. **Aislamiento transparente de fuentes sin documentos:**
   - La base `output/mefp/inventory.db` contiene 0 registros debido al incidente de infraestructura de certificados reportado en B-25. El script detecta esta condición y clasifica a MEFP con el estado `SIN_DOCUMENTOS` (sin fallar ni alterar el conteo de portales activos: 26 activos + 1 inactivo).
2. **Suma de Datasets y Volumen Acumulado:**
   - Además de las filas y recursos únicos, el comando extrae de SQLite el total de datasets activos (59) y el peso neto en bytes de los documentos procesados (646.03 MB), aportando una visibilidad completa de la volumetría de la Etapa C.
