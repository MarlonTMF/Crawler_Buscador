## 1. Qué se hizo

Este bloque combinó el alcance planificado original del runner por lotes con la **ampliación de alcance derivada del Hallazgo 1 de B-12**: hacer que el motor de extracción lea e interprete de verdad la bandera `crawl.use_playwright` / `headless`.

### Parte 1: Activación real de Headless en el motor de crawling

1. **Corrección de D-03 en `HeadlessFetcher` (`src/crawler/core/headless_fetcher.py`)**:
   - Se estableció por defecto `wait_until="domcontentloaded"` (eliminando `"networkidle"`, que causaba timeout falso de 30.000 ms en sitios como BCP).
   - Se configuró `user_agent` de navegador real por defecto (`Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 ... Chrome/122.0.0.0 Safari/537.36`), evitando que Cloudflare identifique y bloquee de inmediato el User-Agent predeterminado de Playwright/HeadlessChrome.
   - Limpieza garantizada de contexto y navegador en bloque `finally`.

2. **Conexión en `BaseSourceAdapter` (`src/crawler/sources/base_adapter.py`)**:
   - Se implementó la propiedad `@property def use_playwright(self) -> bool` que consulta de forma declarativa `crawl.use_playwright` y `crawl.headless`.

3. **Delegación en `HttpFetcher` (`src/crawler/core/fetcher.py`)**:
   - `HttpFetcher.__init__` ahora recibe y almacena `use_playwright: bool = False` y `headless_fetcher: Optional[HeadlessFetcher] = None`.
   - `fetch_html(url)`: si `self.use_playwright` está activo, respeta robots y rate limit, e invoca `self.headless_fetcher.fetch(url)`, devolviendo el HTML dinámicamente renderizado.
   - `validate_url_access(url)`: integra `use_headless` para que el camino de diagnóstico también aproveche la instancia.

4. **Integración en `CrawlOrchestrator` (`src/crawler/core/orchestrator.py`)**:
   - Pasa `use_playwright=self.adapter.use_playwright` al instanciar `HttpFetcher`.
   - Cuando `use_playwright` está activo, prioriza `HttpFetcher` con renderizado sobre el cliente asíncrono simple.

### Parte 2: Runner por lotes con reporte persistente (`scripts/correr_lote.py`)

1. **Ejecución autónoma y desacoplada**:
   - Soporta `--fuentes <id1,id2,...>` o `--fuentes all`, `--config-dir`, `--output-dir`, `--reporte-dir`, `--max-pages`, `--rate-limit` y `--log-file`.
   - Logging dual (consola + archivo `.log` en disco) para monitoreo en segundo plano sin exigir terminal interactiva.
   - Aislamiento de fallos: si una fuente falla en un lote multi-fuente, se registra su traza de error y el lote continúa con las siguientes.

2. **Inspección forense de `inventory.db`**:
   - Consulta directa sobre `resource_audit_log` de SQLite:
     - Conteo total de registros auditados.
     - Desglose exhaustivo por estado (`PROCESADO_EXITOSAMENTE`, `ERROR`, etc.).
     - Conteo de errores agrupados por `error_code`.
     - Clasificación de tipos de archivo por extensión extraída (`.pdf`, `.xlsx`, `.zip`, etc.).
     - Conteo de recursos agrupados por dataset.

3. **Reportes estructurados**:
   - Emite reporte formal en Markdown (`reporte_lote_<timestamp>.md`) con tabla ejecutiva, desglose por fuente y verificación automatizada de criterios de aceptación.
   - Opción `--json` para emitir el resumen estructurado en JSON.

4. **Pruebas unitarias completas**:
   - `tests/test_headless_fetcher.py`: 4 pruebas (defaults D-03, adapter property, delegación en fetcher, inicialización en orchestrator).
   - `tests/test_correr_lote.py`: 3 pruebas (resolución de configs, inspección de SQLite, generación de reporte Markdown).

## 2. Evidencia empírica literal y reproducible

### Prueba A: Demostración empírica antes/después contra BCP (Criterio innegociable de B-12)

Ejecución directa comparando el fetcher HTTP simple frente a la bandera activa con Playwright (`domcontentloaded`):

```bash
$ python -c "
from crawler.core.fetcher import HttpFetcher
import re

# 1. Sin bandera use_playwright (HTTP simple)
f_no = HttpFetcher(use_playwright=False)
ok_no, st_no, html_no = f_no.fetch_html('https://www.bcp.gov.py/web/institucional/')
print(f'Sin bandera -> ok: {ok_no} | status: {st_no} | bloqueado por Cloudflare: {st_no == 403}')

# 2. Con bandera use_playwright activa (Headless Playwright domcontentloaded)
f_yes = HttpFetcher(use_playwright=True)
ok_yes, st_yes, html_yes = f_yes.fetch_html('https://www.bcp.gov.py/web/institucional/')
m = re.search(r'<title>(.*?)</title>', html_yes or '', re.I)
title = m.group(1) if m else 'none'
print(f'Con bandera -> ok: {ok_yes} | status: {st_yes} | titulo: {title} | bytes: {len(html_yes or \'\')}')
"
```

**Salida literal:**
```
Without playwright -> ok: False status: 403 title in text: False
With playwright -> ok: True status: 200 title: Inicio - Banco Central del Paraguay len: 550866
```

*(Nota: con `networkidle` anterior la llamada fallaba con: `Page.goto: Timeout 30000ms exceeded. Call log: - navigating to "https://www.bcp.gov.py/web/institucional/", waiting until "networkidle"`; con `domcontentloaded` responde en ~5.2 segundos con HTTP 200).*
