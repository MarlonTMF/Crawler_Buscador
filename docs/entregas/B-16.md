## 1. Ajuste de Robustez en Motor (src/crawler/core/fetcher.py)

Durante la prospección de ASOFIN, el servidor www.asofinbolivia.com abortaba conexiones HTTPS ([WinError 10061] No se puede establecer una conexión ya que el equipo de destino denegó expresamente dicha conexión).

En HttpFetcher.fetch_head, la línea 489 ejecutaba if attempt == self.max_retries: raise, lo que propagaba una excepción no capturada abortando la corrida del crawler ante enlaces rotos o desalineaciones de subdominio.
Se corrigió para retornar (False, 0, {}) de forma coherente con fetch_html y el resto del ciclo de vida del fetcher.
